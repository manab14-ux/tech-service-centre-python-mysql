# Tech Service Centre Management System
**Developer:** Manab Das | B.Tech CSE, Lovely Professional University

## 1. Purpose
A menu-driven management system designed to automate customer repair logs, service status tracking, and billing records for an electronics service centre.

## 2. Tools & Technologies
- **Language:** Python 3
- **Database:** MySQL
- **Connectivity:** mysql-connector-python

## 3. Implementation
Implemented CRUD (Create, Read, Update, Delete) operations allowing staff to register new repair requests, check pending deliveries, and generate final customer invoices directly from the terminal.

## 4. Outcome
Replaced manual register entry with a structured relational database, reducing record lookup time and billing errors.
